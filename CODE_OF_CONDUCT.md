# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful, assume good faith, no harassment of any kind.
Technical disagreement is welcome: argue with evidence, not with people
(fittingly, that is also how the harness settles its RFCs).

**En corto:** respeto, buena fe, cero acoso. El desacuerdo técnico es
bienvenido: se litiga con evidencia, no contra personas (igual que los RFCs
del propio harness).

Reports: open a private report via GitHub (Security tab) or contact the
maintainer through their GitHub profile. Reports are handled confidentially.
